# Pre-agree a directional TLP-to-H0-H3 translation framework with cross-sector and cross-border partners before a joint cybercrime investigation begins

## Summary

Establish, ahead of an incident, a documented direction-by-direction mapping between TLP levels and EU H0-H3 handling codes with each private-sector and cross-border law-enforcement partner an organization expects to work with, so that a shared understanding of default handling and required approvals exists before urgent evidence-sharing decisions have to be made under time pressure.

## Addresses

- [[weaknesses/Restrictive default information-sharing handling codes delay cross-border cybercrime evidence from becoming usable in judicial proceedings]]

## How To Apply

As part of pre-incident readiness planning, agree with each regular collaboration partner (CSIRTs, private incident responders, and cross-border law-enforcement counterparts) which TLP level corresponds to which H0-H3 code for each direction of information flow relevant to the partnership, and what conditions or provider approval each mapping requires for onward use in a criminal case file. Record this agreement alongside other pre-incident collaboration mechanisms (shared protocols, secure communication channels, and escalation paths), and operationalize it in the case management system used during an investigation so that every ingested item is logged with its source, its original classification, and its translated handling code from the moment it is received, rather than reconciling classifications reactively once a formal request becomes urgent.
