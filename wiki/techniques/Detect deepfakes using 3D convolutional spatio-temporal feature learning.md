# Detect deepfakes using 3D convolutional spatio-temporal feature learning

## Summary

Because a deepfake video is generated by manipulating each frame separately, the resulting inconsistencies are not confined to a single frame's spatial content but also manifest across the temporal dimension between adjacent frames; a 3D convolutional network, whose kernels slide across both the spatial dimensions and a stacked sequence of frames simultaneously, learns these joint spatio-temporal irregularities directly, rather than requiring a separate frame-level CNN and a subsequent recurrent layer to combine per-frame features after the fact.

## Details

The face region is extracted from each frame at a consistent spatial location across a consecutive sequence of frames (16 frames performed best in ablation testing against 32, 24, 8, and 4 frame sequences), and these aligned face crops are stacked into a single 3D input volume (128x128x16x3). A deep 3D-CNN (five convolution/batch-normalization/ReLU/max-pooling blocks, growing from 8 to 128 feature maps while spatial dimensions shrink each layer and the temporal dimension shrinks only from the second layer onward) processes this volume directly, followed by dropout and two fully-connected layers producing a binary real/fake classification. Because temporal dimension reduction is delayed relative to spatial reduction, the network preserves more inter-frame relationship information in its earlier layers before progressively compressing it, and the resulting model is comparatively lightweight (about 1.3 million parameters) relative to some spatial-only competing architectures.

## Examples

- On FaceForensics++ (Deepfake subset), the 3D-CNN model reached 99.4% and 94.5% binary detection accuracy on the high-quality and low-quality video subsets respectively, exceeding seven prior spatial-only detection methods compared in the same study (steganalysis features, transferable deep-CNN, recasting residual-based local descriptors, MesoNet, XceptionNet, and a recurrent-convolutional strategy).
- On the VidTIMIT dataset, the same architecture reached 99.7% and 99.2% accuracy on high- and low-quality subsets respectively, again exceeding all compared prior methods.
- Ablation testing across different consecutive-frame sequence lengths (32, 24, 16, 8, and 4 frames) found 16 frames gave the best accuracy-to-parameter-count trade-off, informing the final architecture's input volume depth.
