# Mutated cross-model ensemble detection of adversarial classifier evasion

## Summary

Adversarial examples are typically crafted against a specific target model or feature space, and while some transfer to other models, that transferability is imperfect and distance-limited. Because an adversarial example sits near a classifier's decision boundary by construction (that is exactly what makes the small perturbation effective), even a modest change to the model — different hyperparameters, or a different underlying algorithm — is more likely to flip its predicted label than it is to flip the label of an authentic, non-adversarial input, which sits further from the boundary.

## Details

Starting from an original well-performing model (e.g., an SVM), a group of "mutated" classifiers is generated by randomly varying algorithm-specific hyperparameters (e.g., SVM kernel type and regularization; k-NN's number of neighbors; decision tree depth and leaf constraints; random forest's number of estimators) across six base machine-learning families (SVM, k-NN, Naive Bayes, Logistic Regression, Decision Tree, Random Forest), retaining only mutants whose performance on a held-out test set is comparable to the original model. For a query example, its Prediction Inversion Rate (PIR) is the fraction of mutated models whose prediction differs from the original model's prediction; PIR is calibrated against a baseline computed from known-benign examples, and an example exceeding an adjustment-factor-scaled threshold above that baseline is flagged malicious/adversarial.

## Examples

- Evaluated against mimicry, reverse-mimicry (Mimicus), and gradient/genetic-programming attacks (EvadeML-P, EvadeML-H) on a dataset of 11,200 malicious and 10,500 benign PDFs using a 700-model mutation group, the method achieved higher accuracy (0.9975-0.9981 AUC across attack types) than three compared state-of-the-art detectors (PJScan, PDFRate, Hidost), which each dropped substantially against at least one attack type (e.g., PDFRate to 0.6398 AUC against EvadeML-H).
