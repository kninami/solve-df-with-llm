# Repair compressed forensic filesystem images using statistical bitflip correction

## Summary

Flash storage naturally accumulates single-bit errors ("bitflips") over time and during data transfer or extraction; a block-compression format like gzip's DEFLATE is only affected within the specific block a bitflip occurs in, unlike a whole-stream algorithm like LZMA where a single bitflip corrupts everything after it. By estimating the overall bitflip rate from the fraction of already-corrupted fragments (using a Bernoulli/Binomial error model validated with Hoeffding's inequality), an examiner can predict how many bitflips are likely in each remaining corrupted fragment and search only that much smaller space of repair candidates.

## Details

For each corrupted compressed fragment, a set of repair candidates is generated by mutating the fragment with every combination of the estimated number of bitflips (starting with one, since the model predicts single-bitflip fragments dominate). A candidate is validated using three checks that together act as a decompression oracle: whether inflating a deflate block succeeds, whether the decompressed data's checksum (e.g., Adler-32) is correct, and whether the decompressed length matches the expected value from filesystem metadata (e.g., an inode table). When independently obtainable metadata such as file length is available, it further narrows valid candidates via a subset-sum-style filter. Where multiple valid candidates remain for a fragment, binary diffing (e.g., in a disassembler) can distinguish a functionally-plausible candidate from an implausible one requiring undefined register use.

## Examples

- On a Google Home's corrupted SquashFS dump, an initial bitflip-rate estimate of ~5×10⁻⁷ (about one bitflip per 248,253 bytes) was refined via single- then double-bitflip repair passes, raising the filesystem's recoverable data from 8.32% (using standard `squashfs-tools` alone) to 99.68% of bits and 99.31% of bytes, repairing 102 of 111 originally corrupt files fully automatically.
