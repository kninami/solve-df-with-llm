# Reinject a tampered image into camera firmware to forge native processing traces

## Summary

Rather than attacking a single forensic trace (metadata, JPEG structure, or compression statistics) in isolation, this anti-forensic technique inverts a tampered image back to raw sensor-buffer format and injects it into a real camera's own image-acquisition pipeline, so that every downstream native trace — including proprietary in-camera processing — is regenerated by the genuine camera firmware rather than approximated by an external tool.

## Details

Implemented against a Canon EOS M using the open-source Magic Lantern firmware add-on, the method reverse-engineers the camera's finite-state-machine-based shooting task (via QEMU emulation and firmware call logging) to identify the exact state transition at which raw sensor data has been written to the acquisition buffer but in-camera processing has not yet begun. A custom firmware module hooks this transition and overwrites the buffer with an inverted (linearization, white-balance, demosaic, and color-space-conversion-reversed) representation of the tampered image, after which the camera's unmodified processing pipeline continues normally, producing an output JPEG/CR2 pair with fully native metadata, JPEG structure, quantization tables (including thumbnail QTs), and single-compression DCT statistics. Because the camera's real firmware performs the processing, the attack simultaneously restores or forges every trace at once rather than requiring a separate technique per trace, and can be used to make computer-generated images look camera-native, spoof a different source camera model, or erase editing software traces from a genuinely tampered image. It cannot correct physically implausible tampering (inconsistent lighting, shadows, or perspective) or hide local splicing/copy-move artifacts, and cannot forge a different camera model's genuine sensor noise (PRNU).

## Examples

- A Photoshop-tampered image of President Obama (originally flagged as suspect due to 21 Photoshop metadata tags, non-standard Quality-Factor-12 quantization tables, and periodic multi-compression DCT artifacts) was reprocessed through Camera Obscura on a Canon EOS M, after which the same forensic analysis found 0 Photoshop tags, quantization tables consistent with a native Canon EOS M capture, and a single-compression Laplace-distributed DCT coefficient pattern — with only a 0.96 SSIM perceptual difference from the original tampered image.
